# AlyHackbart.com Agent Team

This repository follows the AI Development Harness from `ConlinJoe/ai-platform`.

Work stays inside this repository unless the user explicitly authorizes cross-repository work. Do not add dependencies, change deployment configuration, create branches, or make destructive changes without approval. The default branch is the live deployment path, so changes to `main` are production changes.

## Team roles

- `product-design.md`: owns portfolio hierarchy, visual direction, responsive composition, and harness UI constraints.
- `frontend-engineer.md`: owns semantic HTML, CSS, vanilla JavaScript, performance, and framework-native implementation.
- `content-accessibility.md`: owns truthful copy, metadata, accessibility, keyboard/focus behavior, and reduced-motion requirements.
- `qa-release.md`: owns verification, guardrails, live-site checks, regressions, and release reporting.

## Shared rules

1. Preserve the static HTML/CSS/JavaScript architecture unless a real requirement justifies changing it.
2. Never fabricate projects, clients, metrics, awards, testimonials, or capabilities.
3. Do not use decorative sequential numbering or em dashes in generated public-facing copy.
4. Prefer hierarchy, whitespace, meaningful imagery, and clear section boundaries over decorative cards or template conventions.
5. Mobile and accessibility are part of every UI change.
6. Significant UI work requires rendered verification before DONE.
7. Capture unrelated discoveries instead of expanding scope.
8. Report DONE or BLOCKED with the material change, verification performed, and any real human action still required.
