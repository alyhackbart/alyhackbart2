# alyhackbart.com

Cinematic portfolio starter for Aly Hackbart.

## Preview locally
Open `index.html` in a browser.

## Replace placeholders
- Replace the hero `.placeholder` with a video element when your showreel is ready.
- Replace each `.thumb` with a project image/video.
- Update project names, roles, About copy, and contact email.

## Deployment
This is a static site and can be deployed to Google Cloud, GitHub Pages, Cloudflare Pages, or another static host.
