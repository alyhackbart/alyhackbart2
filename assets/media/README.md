# Replaceable Website Media

This folder contains the images and video currently displayed by the website.

Recommended filenames:

- `hero-reel.mp4`: muted looping hero video
- `hero-poster.webp`: image shown before the hero video loads
- `restaurant.webp`: restaurant and hospitality project
- `creator.webp`: creator and social project
- `event.webp`: event project
- `wedding.webp`: elopement or intimate celebration project
- `portrait.webp`: portrait of Aly
- `behind-scenes.webp`: Aly working on a video project

You can replace a file using the same filename, or upload a new filename and update its path in `content/site-content.js`.

When replacing a concept project with real work, set `sample: false` in the matching project entry to remove the Concept sample badge.

See `/EDITING-GUIDE.md` for exact steps, fallback configuration, recommended dimensions, and the static build command.
