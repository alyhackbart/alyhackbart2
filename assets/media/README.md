# Replaceable Website Media

Upload real files to this folder, then point `content/site-content.js` at them.

Recommended filenames:

- `hero-reel.mp4`: muted looping hero video
- `hero-poster.webp`: fallback image shown before the hero video loads
- `restaurant.webp`: restaurant and hospitality project
- `creator.webp`: creator and social project
- `event.webp`: event project
- `wedding.webp`: wedding and celebration project
- `portrait.webp`: portrait of Aly

The current generated concept media remains embedded under `/media/` as a temporary fallback. Uploaded files take priority once their paths are added to `content/site-content.js`.

See `/EDITING-GUIDE.md` for exact steps and recommended dimensions.
